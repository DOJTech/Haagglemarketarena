# Haggle: investor brief (prototype stage)
Built by Dolapo Oyatomi.

**What it is.** A daily market game. Players buy stock, then haggle with six shoppers a day for seven days. Everyone plays the same daily market, so scores are comparable. Country leagues, weekly league, streaks, installable on phones.

**Positioning (accurate).** An early sponsored price-test platform built on a game. It is not an ad exchange.

**What exists today (tested).** Sponsor campaigns with brand-safety rules and owner approval, randomised price tests in practice games only, private brand report links, invoicing records; Server-run, cheat-resistant game engine; public counters; daily and weekly leaderboards by country; moderation and erasure; owner metrics (visitors, testers, plays, repeat players, D1/D7 return, countries); anonymised sponsor insights; installable web app; deployment files.

**Evidence so far.** 95 automated checks pass; 30 simulated players at once ran with no server errors (p95 79 ms on a small machine). There are no real users yet, so there is no traction to claim.

**Business hypotheses (to be tested, not facts).**
1. Brands pay to place a product in the game and to see how shoppers react to prices and promotions.
2. Players pay a little for cosmetics later (never real-money prizes).
3. Aggregated, anonymised shopper-behaviour data is sellable if cohorts are large enough.

**What an investor should ask for next.** D1 and D7 return rates from the Metrics tab after the first 100 to 500 players; the first paid sponsor pilot; the cost to acquire a player in Lagos.

**Key risks.** No users yet; revenue unproven; fake-device farming without sign-in; regulatory review of data use and any prizes; dependence on one founder.
